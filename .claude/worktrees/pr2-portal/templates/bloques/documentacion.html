Cómo usar tu API Key

{% if config.documentacion.variante == "larga" %}

Tu aplicación se autentica contra authservise con el grant client_credentials de OAuth2: primero pide un token con tu client_id y client_secret, y después usa ese token (con vigencia limitada, configurable por request) en cada llamada. 

# 1) Pedís un access token (repetilo cada vez que expire, no hay refresh token)
curl -u "TU_CLIENT_ID:TU_CLIENT_SECRET" \
     -d "grant_type=client_credentials&ttl=1800" \
     https://auth.coupertech.com/oauth/token

# -> {"access_token": "...", "token_type": "Bearer", "expires_in": 1800, "scope": "..."}

# 2) Usás el token en cada request
curl -H "Authorization: Bearer TU_ACCESS_TOKEN" \
     https://auth.coupertech.com/algun-endpoint

El client_secret solo se muestra una vez (al generar la API Key o al rotar el secreto) — guardalo en un gestor de secretos de tu lado, no se puede recuperar después.
